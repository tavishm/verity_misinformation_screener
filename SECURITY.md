# Security policy

This pilot handles potentially sensitive message text. Do not put API keys,
phone exports, screenshots, pairing tokens, local databases, signing keys, or
provider/accounting records in issues, pull requests, commits, or releases.

To report a vulnerability, contact the repository owner privately through the
contact method listed on the repository profile. Include a concise description,
affected version or commit, reproducible steps, and any suggested mitigation.
Please allow time for acknowledgement and a fix before public disclosure.

The project does not currently offer a support or vulnerability-response SLA.

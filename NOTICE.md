# Notice and licensing status

This repository intentionally has no top-level project license yet. Publishing
source code does not by itself grant reuse rights. The project owner must choose
and add a license only after confirming authority to license all included code,
datasets, generated materials, and model-related files.

Some components retain their own upstream terms. In particular, the repository
contains `mobile/classifier/UPSTREAM_LICENSE_GPL-3.0.txt` and
`mobile/classifier/UPSTREAM_MODEL_LICENSE_APACHE-2.0.txt`; the contextual model
notice is in `mobile/android/assets/context-model-notice.txt`. Review those
materials and any dataset terms before making a public release.

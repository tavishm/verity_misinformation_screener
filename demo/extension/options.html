Checking connection…

Your checker runs on this computer and its connected GPU server.

Three steps to your first check

  1. Start the local checker using start-checker.sh from the project folder. Keep the connected GPU machine available.
  2. Choose Connect local checker above. Pin Evidence Check from Chrome’s extensions menu so it’s easy to reach.
  3. Refresh an X or Reddit feed. Choose Check text below a visible public post, then open View evidence. In the popup, turn on Check as I scroll for automatic checks.
Read the scale

1 Surely false · 2 Likely false · 3 Unsure or mixed · 4 Probably true · 5 Sure true.

This experimental backend uses levels 2–4. It reserves definitive ratings until stronger review is available. “No factual claim” has no rating.

Know what was checked

English and Hindi text can be submitted. The current evidence library is small, so many posts will be unsure. Images, video, quoted posts and links’ contents are not verified.

Private by design, local for this demo

Manual checking sends the chosen post text to your local checker. Automatic checking sends visible eligible post text after you turn it on. The checker uses the connected GPU server; no paid model API is used. Automatic checking starts off and has a configurable daily limit.

Use public feeds. Message, chat and settings pages are excluded, and recognizable protected posts are skipped. Platform markup can change. The extension cannot reliably identify every restricted post.

Results can take longer than 15 seconds. A check keeps running after you scroll away; return to the post to see it. This version does not send completion emails. Results are experimental and are not a promise of feed-wide verification.

Connection uses only 127.0.0.1:8870. The extension package contains no API key or pairing token.
